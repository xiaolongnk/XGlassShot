# Screenshot provenance

The README images are unmodified native XGlassShot Build 21 window captures. `demo.html` is the generic design sample captured on the selected display for the preview; it contains no private screen content. The sample is included under the repository MIT license.

Day/Night main windows show the same real saved screenshot. Saving uses a temporary `/Users/Shared/XGlassShot-Demo` folder and `design-review` prefix. The owner's Pictures destination, original prefix, Follow System mode and 25% transparency were restored after capture. The example background is a user-imported system image, not a bundled app asset or default wallpaper.

Use the app on a physical Mac to regenerate screenshots. Do not substitute a mock app window, private work screen or generated UI. The native green focus indicator and macOS screen-sharing indicator are left intact.
