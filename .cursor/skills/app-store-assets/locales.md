# App Store Locales

## Recommended languages and App Store Connect locale codes

| Language | Locale code | Notes |
|----------|-------------|-------|
| English (US) | en-US or en | Default / primary |
| Simplified Chinese | zh-Hans | Mainland China |
| Traditional Chinese | zh-Hant | Taiwan / Hong Kong |
| Japanese | ja | Japan |
| Korean | ko | Korea |
| German | de | Germany |
| French | fr | France |
| Spanish | es | Spain / Latin America |

## Project alignment

- In-app localization uses **en** and **zh-Hans** (see `GlassCap/Localizable.json`).
- Store assets should at least include **en** and **zh-Hans**; add others per target markets.
