GlassCap support

GlassCap is the source project and workspace name. Its existing Mac App Store record is XGlassShot. The app is free and has no subscriptions or in-app purchases.

Take your first capture

  1. Open the app and press ⌘⇧2 or click Screenshot.
  2. Allow Screen Recording access in System Settings → Privacy & Security if macOS asks, then retry.
  3. Drag an area and press Return to capture. Press Esc to cancel.

Use the arrow beside Screenshot to choose a particular display. Press ⌘⇧1 to record a region, then Stop Recording to finish. Recordings currently contain video only.

Save files your way

Open Settings with ⌘,. In Saving, choose the destination folder and filename prefix. Automatic captures use unique names and do not overwrite existing files. Enable Ask where to save if you prefer a save panel.

Appearance and local tools

Appearance supports Day, Night and Follow System, an optional background image and 0–80% background transparency. macOS Reduce Transparency takes priority. Copy Text and Beautify process the current image locally; a video preview does not provide image-only tools.

Recover a recording

If a save was cancelled or failed, use Recover Recordings… in the menu. Keep or delete the files in that folder as needed.

Report an issue

Open a GitHub issue with the app build, macOS version, steps and expected result. For display bugs, include display arrangement and scaling. Use generic examples, not private screen content. Security issues should be reported privately through the repository's Security tab.
