## URLs to replace

- **Support URL:** e.g. `https://yourdomain.com/glasscap/support` or a GitHub repo / docs page.
- **Privacy Policy URL:** Required if you collect or process user data. e.g. `https://yourdomain.com/privacy`. If the app only uses local screen capture and save locations, a short policy stating “no data sent to servers” is still recommended.
